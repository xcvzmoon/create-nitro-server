Create your API and deploy it anywhere with this Nitro Server starter.

## Getting started

```bash
pnpm install
pnpm run dev
```

## Deploying

```bash
pnpm run build
```

Then checkout the [Nitro documentation](https://nitro.build/deploy) to learn more about the different deployment presets.
